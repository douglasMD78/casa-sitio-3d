# Casa do Sítio 3D

Projeto interativo da casa, desenvolvido com Three.js.

## Fluxo de trabalho

- `main`: versão aprovada do projeto.
- Mudanças de ambientes e recursos novos são propostas em branches `feature/*` e revisadas por Pull Requests.
- Não alterar a geometria arquitetônica e os demais cômodos sem solicitação explícita.
- Dados arquitetônicos: `dados/casa.json`.
- Inventário dos cômodos: `dados/comodos/`.
- Motor de visualização: `motor/`.

## Situação
